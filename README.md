# Fox Digital Music — Web

Aplicação web para gerenciamento de músicas.

##  Modificações

**Ângelo Gabriel Menezes Barbosa**

---

## Como Rodar

**Pré-requisitos:** Node.js, Angular CLI e MongoDB instalados, e a API rodando na porta 5000.

```bash
npm install
ng serve
```

Acesse: http://localhost:4200

---

## Melhorias Implementadas

- Filtro por gênero via dropdown ou clicando na barra lateral
- Ordenação por data (mais recentes / mais antigas)
- Filtro por artista ao clicar no nome do cantor
- Indicador visual dos filtros ativos, ex: `Exibindo: Rock • Mais Antigas (2 músicas)`
- Botões ficam destacados quando um filtro está ativo
